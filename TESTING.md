## Limits

- Rise Medical and a Sage installation were not available for live browser tests. The standalone template is theme independent, but website header/footer mode depends on the active theme's `get_header()` and `get_footer()` behaviour; test it on each deployment.
- The local Physio database was unavailable during the 1.1.11 checks, so the new motion and sizing were verified in a browser fixture rather than through a live WordPress page.
- Font files are site-owned. The plugin uses font families and Divi's uploaded-font registration when available, and does not bundle commercial font assets.
- Custom theme CSS outside `.rise-lp` may require a site-specific compatibility rule. The Divi overflow correction is scoped to Rise pages in website layout mode.
